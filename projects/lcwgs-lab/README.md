# Optional lcWGS likelihood lab

One small Python project, up to **10 extra minutes** after the one-hour handwritten course.
Skipping it has no effect on the next sheet. Use the standard library initially; no setup sprint.

Start with `current-task.md` and edit `likelihood.py`. When you want review, submit the code or
change the task's “Ready for review” field to yes. Until then the tutor leaves the task pending.
A changed file alone is not a claim that you finished. Partial submissions get review and keep
the current milestone if more work is needed. Do not create a daily coding backlog.

Run from this folder: `python3 likelihood.py` (an unfinished TODO is expected initially).

Possible future increments, issued one at a time after review:
Phred conversion → one-read probability → heterozygote mixture → multi-read log likelihood →
posterior normalization → one-site allele-frequency likelihood → one EM step → a tiny
simulated coverage experiment. These are a roadmap, not assigned homework. The toy model
is for understanding assumptions and does not replace ANGSD's production likelihood models.

Tutor: preserve the learner's implementation. Record feedback in `review-log.md`, update
`state.json`, and replace the current task only after a reviewed milestone is ready to advance.
Do not implement pending learner functions yourself.
