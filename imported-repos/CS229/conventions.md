# CS229 Formatting Conventions

- **Page Size**: 6.2in x 8.27in (Kindle Scribe native 1860x2480 @300ppi).
- **Format**: Typst -> PDF.
- **File Naming**: `cs229 day 01.pdf` and `day-01.typ`.
- **Teaching Rules**:
  - No self-grading (instructor grades off PDF).
  - Misses print mechanism, not fact.
  - One degree of freedom per question.
  - Prefer reconstruct over recall.
- **Structure**:
  - Page 1: 5-card drill (spaced repetition).
  - Page 2 top: Timer block.
